# Library Management System

## About the Project
A Library Management System developed using Python and Django.

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## Features
- Student Registration
- Login System
- Book Management
- Issue Books
- View Library Books

## Installation
1. Install Python.
2. Install the required packages:
   pip install -r requirements.txt
3. Run the server:
   python manage.py runserver
